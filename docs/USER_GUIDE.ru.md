# NoteShaper 0.5.2 — инструкция

[English](USER_GUIDE.en.md) · [Главная](../README.ru.md)

## Совместимость

Готовые архивы NoteShaper 0.5.2 содержат **Windows x64 VST3** и, в полном комплекте, отдельное приложение для Windows. Плагин предназначен для 64-битных DAW с поддержкой VST3.

| Платформа и DAW | Статус |
|---|---|
| Windows x64, Ableton Live с VST3 | Подходит по формату. Проверки выполнены в отдельном VST3-хосте; сам Live не тестировался. |
| Windows x64, FL Studio с VST3 | Ожидается работа как эффекта микшера. FL Studio поддерживает VST3, но NoteShaper в самой FL пока не тестировался. |
| Windows x64, другая DAW с VST3 | Совместимость по формату ожидается; конкретную DAW нужно проверить. |
| macOS, включая Intel и Apple Silicon | Готовой сборки нет. Windows-плагин из этих архивов на macOS не работает. |

Для macOS потребуется отдельная сборка исходников C++/JUCE под Intel/Apple Silicon и проверка в целевой DAW. Поддержка VST3 программой FL Studio или Ableton на Mac не делает Windows-сборку совместимой. См. [сборку из исходников](BUILD.ru.md) и [официальное пояснение Image-Line о разных версиях плагинов для Windows/macOS](https://www.image-line.com/fl-studio-learning/fl-studio-online-manual/html/basics_externalplugins.htm).

## Установка на Windows

1. Скачайте VST3-архив или полный комплект из [Releases](https://github.com/alexeyPetrushin/NoteShaper/releases/latest) и распакуйте его.
2. Закройте DAW и другие приложения, использующие плагин.
3. Внутри распакованного комплекта найдите **папку** `VST3/NoteShaper.vst3`. Скопируйте её целиком в одну из папок VST3, которые сканирует ваша DAW. Сохраните структуру `Contents`, `x86_64-win` и `Resources`; отдельный файл внутри пакета не заменяет весь плагин.
4. Включите соответствующий источник VST3 в настройках DAW и пересканируйте плагины.
5. Добавьте NoteShaper как **аудиоэффект** на дорожку или канал микшера с отдельным сухим вокалом, до реверберации и дилея.

### Как выбрать папку VST3

Путь зависит от Windows и настроек DAW. `C:\Program Files\Common Files\VST3` — распространённый стандартный путь, а не обязательный путь для каждого компьютера. Чтобы открыть системный каталог без привязки к букве диска, вставьте **`%CommonProgramFiles%\VST3`** в адресную строку Проводника. Если папки ещё нет, её можно создать; системный каталог может потребовать права администратора.

| Вариант | Куда копировать `NoteShaper.vst3` |
|---|---|
| Общая системная папка | `%CommonProgramFiles%\VST3`. Предпочтительный вариант для нескольких DAW и для FL Studio. |
| Только для текущего пользователя | `%LOCALAPPDATA%\Programs\Common\VST3`, если ваша DAW сканирует этот пользовательский каталог. |
| Своя папка | Отдельная папка для VST3, явно выбранная в настройках DAW. Используйте её только при поддержке пользовательских путей VST3. |

Стандартные расположения описаны [Steinberg](https://steinbergmedia.github.io/vst3_dev_portal/pages/Technical%2BDocumentation/Locations%2BFormat/Plugin%2BLocations.html); поддержка каждого расположения зависит от хоста. Устанавливайте только пакет `NoteShaper.vst3`: исходники, инструкции и standalone не нужно помещать в папку сканирования.

### Ableton Live на Windows

В **Settings/Preferences → Plug-Ins** включите **VST3 System Folders** для системной установки. Для своей папки включите **VST3 Custom Folder** и выберите каталог, в который скопирован пакет. Не назначайте один путь одновременно системным и пользовательским источником или папкой VST2. Выполните **Rescan**, затем найдите NoteShaper в браузере плагинов. Названия пунктов зависят от версии и языка Live. [Инструкция Ableton](https://help.ableton.com/hc/en-us/articles/209071729-Using-VST-plug-ins-on-Windows).

### FL Studio на Windows

Для VST3 руководство Image-Line требует стандартные расположения: **`%CommonProgramFiles%\VST3`** или **`%ProgramFiles%\VST3`**. Произвольная папка, добавленная в поиск VST2, не гарантирует обнаружение VST3. Откройте **Options → File settings → Manage plugins**, включите **Verify plugins** и запустите **Find installed plugins**. После сканирования загрузите NoteShaper в слот эффекта микшера на канале вокала. [Установка плагинов](https://www.image-line.com/fl-studio-learning/fl-studio-online-manual/html/basics_externalplugins.htm) · [Plugin Manager](https://www.image-line.com/fl-studio-learning/fl-studio-online-manual/html/envsettings_files.htm).

### Другие DAW

Используйте руководство своей DAW: проверьте поддержку **VST3 x64**, включённые каталоги и способ повторного сканирования. Папка для VST2 или библиотек сэмплов не обязательно является папкой VST3.

### Обновление

Закройте DAW, сохраните прежний пакет вне всех папок сканирования, замените `NoteShaper.vst3` целиком и пересканируйте. Проверьте остальные включённые каталоги на дубликаты. NoteFollow и NoteShaper используют общий идентификатор VST3 для старых проектов; одновременно устанавливайте только одну версию.

### Если плагин не появился

Проверьте Windows x64 и VST3, содержимое пакета, выбранный каталог и результаты сканирования DAW. Если DAW пометила прежнюю копию как проблемную, выполните повторную проверку средствами её менеджера плагинов. При обращении за помощью укажите версию Windows, DAW и NoteShaper, путь установки и сообщение сканирования.

## Язык интерфейса

Новая копия открывается на английском. Нажмите кнопку **EN** справа вверху, чтобы включить русский. Она станет **RU**; повторное нажатие вернёт английский. Выбор сохраняется при повторном открытии и в проекте. Список режимов слева расположен над клавишами. В английском интерфейсе «Коррекция» — Correction, «Мягко / Плотно / Рэп» — Gentle / Tight / Rap.

## Выбор цели

| Режим | Действие |
|---|---|
| **Нота** | Нажмите нужную клавишу C, C#, D и так далее. Плагин выбирает ближайшую к голосу октаву. |
| **Аккорд** | Справа выберите Minor/минор, Major/мажор или другой тип. Клавиша выбирает основной тон и переносит весь аккорд. |
| **Гамма** | Справа выберите лад, клавишей — тонику песни. Доступны пять гамм. |
| **Свой набор** | Включайте и исключайте отдельные допустимые ноты. |
| **MIDI** | Задавайте ноты с MIDI-дорожки или клавиатуры. |

Список Note/Нота, Chord/Аккорд, Scale/Гамма, Custom/Свой набор и MIDI находится слева над клавишами. Тип аккорда или гаммы выбирается справа на той же строке. Клавиши C, C#, D и далее всегда видны: в «Аккорде» переносится весь аккорд с сохранением типа, в «Гамме» меняется тоника, в «Ноте» — единственная цель, в «Своём наборе» — отдельные допустимые ноты. Основной тон выделен тёмным; остальные ноты аккорда или гаммы отмечены тонкой чертой. Строка «Вести к» перечисляет все допустимые ноты. При переходе в «Свой набор» текущий аккорд или гамма сохраняется; пустой набор оставляет исходную высоту. В MIDI клавиши показывают поступающие ноты и недоступны для ручного выбора.

В блоке «Коррекция» нажмите «Мягко», «Плотно» или «Рэп», либо сразу двигайте три ручки.

Для мелодии обычно подходит гамма песни: у мажорного аккорда только три ноты, у мажорной гаммы — семь. Аккорд не создаёт дополнительные голоса. При всех способах выбора плагин корректирует один голос к ближайшей допустимой ноте.

## Три крутилки

**Сила** — степень подтяжки высоты: 0% оставляет исходную высоту, 100% полностью следует цели. Промежуточное значение корректирует часть расстояния в центах; это не смесь двух звуков.

**Время** — плавность коррекции. 0 мс даёт резкие ступени; более высокие значения растягивают подтяжку, в том числе в начале фразы. Этот параметр не меняет задержку обработки 64 мс.

**Допуск** — разрешённые мелкие отклонения. Если ошибка укладывается в допуск, она сохраняется. При большей ошибке исправляется только превышение. Поэтому ненулевой допуск оставляет отклонение от центра ноты. 100 центов = один полутон.

Двигайте крутилку вверх/вниз либо нажмите число под ней и введите значение.

## Отправные настройки

| Настройка | Сила | Время | Допуск | Сохранить вибрато |
|---|---:|---:|---:|---|
| **Мягко** | 55% | 85 мс | 8 центов | Включён |
| **Плотно** | 90% | 14 мс | 2 цента | Выключен |
| **Рэп** | 100% | 0 мс | 0 | Выключен |

Три кнопки «Мягко», «Плотно» и «Рэп» постоянно видны справа от «Коррекция». Они сохраняют выбранные ноты. Ручное изменение любого из их параметров снимает выделение готовой настройки.

Для сильного эффекта выберите «Рэп». Если нужно намеренно ограничить голос одной высотой, используйте «Нота»; для ступенчатой мелодии — гамму песни. Для аккуратной правки начните с «Мягко», прослушайте переходы и подстройте силу и время.

**Сохранить вибрато** подтягивает сглаженный центр высоты и сохраняет больше быстрых малых движений, включая вибрато. Также он удерживает цель при коротких колебаниях около границы двух нот. Крупные переходы не ждут проверки длительности. Это упрощённый алгоритм; результат зависит от голоса и настроек.

## MIDI

1. Создайте в DAW MIDI-дорожку или источник MIDI с клипом/входом клавиатуры.
2. Направьте его MIDI-сообщения **во вход NoteShaper** на канале вокала. Способ маршрутизации зависит от DAW: используйте её инструкцию по отправке MIDI в аудиоэффекты.
3. Выберите **MIDI** в списке слева над клавишами плагина. Для ручного выбора вернитесь к «Ноте», «Аккорду», «Гамме» или «Своему набору».

В Ableton Live это настраивается на MIDI-дорожке через **MIDI To**: сначала аудиодорожка с NoteShaper, затем сам плагин. В других DAW названия меню и порядок действий отличаются. Если MIDI в плагин не приходит, для коррекции доступны ручные режимы выбора цели.

Нажатые MIDI-ноты задают допустимые классы высоты; их октавы не задают точную октаву вокала. Аккорды задают несколько целей для одного голоса. Sustain (CC64) удерживает отпущенные ноты до отпускания педали, независимо для каждого канала.

Без нажатых или удержанных педалью нот высота не меняется. Ручной выбор при MIDI недоступен. All Sound Off снимает все удержанные ноты данного канала, Reset Controllers сбрасывает педаль.

## Показания и проверка на слух

Внизу справа видны распознанная и целевая ноты, а также текущая коррекция в центах. Показания не отвлекают от выбора цели и трёх ручек. «Ждёт голос» означает, что устойчивый голос пока не найден. «MIDI: ждёт ноты» означает, что MIDI не задаёт целей.

Сравните обработку с исходным вокалом и слушайте начало слов, окончания и переходы между нотами. При неверных нотах сначала проверьте гамму и тонику. При слишком заметной правке увеличьте время, снизьте силу или включите «Сохранить вибрато». Пустой набор и 0% должны оставлять исходную высоту.

## Ограничения

Один голос, примерно 65–1000 Гц. На смешанном вокале с аккомпанементом, шуме, хрипе, придыхании и больших скачках возможны ошибочные цели и артефакты. Плагин не распознаёт тональность песни автоматически.

Фиксированная задержка 64 мс сообщается DAW для компенсации при воспроизведении; живой мониторинг остаётся запаздывающим. Форманты, транспонирование, гармонизация и редактор отдельных нот не входят в эту версию.

Если есть полная сборка, `Standalone/NoteShaper.exe` позволяет открыть интерфейс без DAW. Она не устанавливает VST3 автоматически.
